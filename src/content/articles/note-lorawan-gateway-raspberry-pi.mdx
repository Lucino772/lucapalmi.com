I finally wired a LoRa concentrator to a Raspberry Pi and pointed it at a network server. The hardware part took ten minutes; understanding what the packet forwarder actually does took the rest of the evening.

What surprised me:

- The gateway is almost dumb. It forwards every packet it hears and lets the network server deduplicate.
- Range is less about the radio and more about where the antenna sits. Moving it one floor up doubled what I could reach.
- Logs are the best documentation. Watching `uplink` frames arrive taught me more than the spec did.

```sh
journalctl -u lora-pkt-fwd -f | grep rxpk
```

Next step: a sensor node on battery, and seeing how long it lasts when it only wakes up to talk.
