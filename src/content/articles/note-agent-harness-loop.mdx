The loop itself is a few dozen lines: send context, get a tool call, run it, repeat. Everything that makes it usable lives around that loop.

Where the time actually goes:

1. **Environments.** The same agent has to run on a laptop, in a container and on a remote machine, and behave the same way.
2. **Boundaries.** Deciding what a tool is allowed to touch is a product decision disguised as a security one.
3. **Observability.** If you cannot replay what happened, you cannot improve it.

It looks a lot like building any other distributed system, which is probably why I enjoy it.
